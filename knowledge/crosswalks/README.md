# Crosswalks

Crosswalks are evidence-backed mappings between source-native concepts.

## Rule

A mapping is never just `A = B`. It must record source object, target object, mapping strength, rationale, evidence, reviewer and last verified date.

## Mapping strengths

- `exact`
- `strong`
- `partial`
- `contextual`
- `none`
