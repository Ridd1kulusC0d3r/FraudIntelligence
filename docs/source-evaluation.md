# Source Evaluation

FraudIntelligence separates **source quality** from **analytic confidence**.

| Dimension | Values | Question |
|---|---|---|
| Reliability | high / medium / low / unknown | Does this source consistently provide dependable material? |
| Method transparency | high / medium / low / unknown | Can we understand how the claim was produced? |
| Evidence proximity | direct / near-direct / indirect / unknown | How close is the source to the underlying event/evidence? |
| Independence | primary / independent-secondary / derivative / unknown | Is this genuinely independent evidence or repetition? |

This is a project-local model, not an official NATO/Admiralty rating system.

Confidence belongs to the assessment, not the publisher. ICD 203 is the tradecraft reference for explicit source quality, uncertainty, alternatives and relevance.

Primary reference: https://www.dni.gov/files/documents/ICD/ICD-203.pdf
