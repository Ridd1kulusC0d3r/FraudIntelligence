# Watch & Warning

Watch & Warning converts a static knowledge base into a system that notices meaningful change.

~~~text
PIR → hypothesis → signposts → threshold → trigger → assessment update → detection/control review
~~~

A signpost is not proof. It is a predefined observation that should change attention, collection or confidence.

Rules:
- thresholds are explicit before a trigger occurs;
- one vendor report should not automatically trigger a strategic warning;
- independent corroboration matters;
- warnings state what changed and which defensive decision should be reviewed.
