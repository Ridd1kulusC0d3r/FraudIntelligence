# Crime Science for Fraud Intelligence

Cybersecurity explains systems well. Crime science helps explain sequences, opportunities and intervention points.

## Crime Script Analysis

Represent fraud as ordered scenes rather than a single event.

```text
preparation → target acquisition → contact/access → positioning
→ action → transfer → monetization → concealment/recycling
```

Each scene can contain:
- prerequisites;
- actor roles;
- channels;
- artifacts;
- decisions;
- observables;
- controls;
- alternative branches.

This representation complements F3. A TTP describes behavior; a crime script describes where that behavior occurs in the operation.

## Situational Crime Prevention

Use prevention questions rather than moral assumptions:

- Can we increase required effort?
- Can we increase probability of detection?
- Can we reduce obtainable value?
- Can we remove enabling conditions?
- Can we introduce a capable guardian or independent confirmation?

Examples include step-up verification, transfer cooling periods, beneficiary risk checks, device continuity signals and recovery controls.

## Routine Activity Theory

For analytical use, model:
- motivated offender / fraud operation;
- suitable target or exploitable process;
- absent or ineffective guardian.

In digital fraud, a guardian can be a person, workflow, control, policy or technical system.

## Triple-label model

FraudIntelligence proposes a useful research representation:

```text
crime-script scene
+ behavioral TTP
+ manipulation pattern
```

Example:

```text
scene: victim engagement
behavior: impersonation / social engineering
manipulation: authority + urgency + isolation
```

This is more expressive than forcing every observation into a single framework.
