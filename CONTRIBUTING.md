# Contributing

Contributions are welcome when they improve defensive fraud intelligence.

## Good contributions

- new primary sources;
- corrections with evidence;
- framework/version updates;
- defensive detection hypotheses;
- mappings with explicit rationale;
- regional fraud intelligence;
- anonymized, lawful research datasets;
- schema and validation improvements.

## Required for knowledge changes

Include primary source when available, date/version, source class, confidence, last verified date and a clear distinction between fact, vendor claim and inference.

## Out of scope

Do not submit content that materially enables fraud execution, credential theft, bypassing anti-fraud controls, cash-out/laundering optimization, victim-targeting scripts or operational evasion.

## Mapping changes

Cross-framework mappings must include semantic rationale. Similar wording alone is not enough.
